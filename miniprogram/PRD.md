## 一、产品概述

### 1.1 产品定位
**拾路派** 是一款 **AI 智能旅行规划工具**，帮助用户快速生成个性化行程、探索旅行灵感、管理旅行计划。原为微信小程序，现扩展为响应式 Web 应用。

### 1.2 核心价值

| 维度 | 说明 |
|------|------|
| 目标用户 | 18-40 岁自由行爱好者、徒步爱好者、旅行规划人群 |
| 核心场景 | 旅行前规划 → 途中路线调整 → 旅行后分享记录 |
| 差异化优势 | AI 一键生成行程 / 徒步路线专项规划 / 路线版本管理 / 日历同步 |

### 1.3 产品 Slogan
> **拾路派 · AI 智能旅行规划**

## 三、功能规格

### 3.1 发现页（广场）

| 功能模块 | 详细描述 |
|---------|---------|
| **瀑布流** | 双列瀑布流布局展示行程卡片，根据封面图高度动态分配左/右列，模拟小红书风格 |
| **搜索** | 顶部搜索栏输入目的地关键词，确认后筛选广场行程 |
| **城市筛选** | 底部弹窗多选城市：定位当前城市 → 热门城市 → A-Z 字母分组城市列表，支持多选标签展示 |
| **天数筛选** | 下拉选择器：全部时长 / 2天1晚 / 3天2晚 / 4天3晚 / 5天4晚 / 7天+ |
| **行程卡片** | 封面图 + 天数标签（左上角）+ 标题 + 用户头像 + 用户名 + 点赞数 |
| **发布入口** | 右上角编辑图标按钮，点击跳转规划页创建新行程 |
| **空状态** | 无数据时展示"暂无行程数据"引导文案 |

### 3.2 规划页（核心页）

| 功能模块 | 详细描述 |
|---------|---------|
| **目的地搜索** | 输入框 + 箭头按钮，支持输入城市/景点名称 |
| **行程日期** | 起始日期选择器 + 结束日期选择器，中间展示天数（自动计算），天数可点击弹出 1-7 天选择 |
| **起止位置** | 起点 A / 终点 B 两个输入框，中间互换按钮 |
| **出行偏好** | 下拉选择：轻松休闲 / 网红打卡 / 小众探索 / 文化体验 / 美食之旅 / 户外冒险 |
| **出行方式** | 下拉选择：自驾 / 徒步 / 公交（选择"徒步"时展开徒步专属表单） |
| **预算档位** | 下拉选择：经济实惠 / 中等预算 / 高端享受 |
| **徒步模式** | 选择徒步后展开专属表单，包含：路线类型（环线/单程/往返等）、难度等级（1-5星）、景观偏好、路况要求、体力限制、交通限制、露营需求开关、附加需求 |
| **必去景点** | 标签式输入，支持添加/删除景点标签 |
| **AI 生成行程** | 提交后调用后端 AI 生成，轮询等待（最长 90 秒），成功后展示完整行程 |
| **行程结果展示** | 统计卡片（总距离/天数/途经点数）+ 日行程时间线（排序按钮）+ 日切换按钮 |
| **徒步结果展示** | 徒步模式下额外展示：总里程/累计爬升/累计下降/预计时长 + 难度星级 + 分段路线详情 |
| **酒店推荐** | 当天住宿推荐卡片（AI 推荐/已选酒店/空状态三种模式），支持查看附近酒店、地图查看、致电 |
| **保存行程** | 保存到"我的行程"，成功后跳转个人中心 |
| **发布行程** | 自动获取封面图，发布到广场 |
| **重新生成** | 保留当前版本为备份，重新生成全新行程 |
| **版本管理** | 底部弹窗：保存当前行程为快照、查看历史版本列表、恢复任意历史版本 |
| **日历同步** | 一键全部添加 或 逐条确认，将每天行程添加到系统日历 |
| **智能推荐** | 基于旅行历史推荐目的地，点击自动填入并触发生成 |
| **底部工具栏** | 固定底部五个按钮：同步日历 / 查看路线 / 重新生成 / 发布 / 更多（版本管理） |

### 3.3 我的页

| 功能模块 | 详细描述 |
|---------|---------|
| **用户信息卡** | 头像 + 昵称 + 城市 + 简介，登录后展示编辑入口，未登录展示"登录/注册"按钮 |
| **数据统计** | 四格统计：行程数 / 发布数 / 收藏夹 / 关注数，点击可跳转对应页面 |
| **最近行程** | 卡片内嵌展示最新 5 条行程，每条显示标题/目的地/天数/状态（进行中/已完成），支持编辑/删除 |
| **出行偏好** | 默认出行方式（自驾/步行/公交/打车）、预算档位（经济/中端/高端）、游玩风格（休闲/深度/小众/亲子/美食） |
| **通用设置** | 消息通知开关、定位服务开关、深色模式开关 |
| **其他** | 关于我们、帮助与反馈、检查更新 |
| **退出登录** | 确认弹窗后退出，清空本地状态 |

### 3.4 行程详情页

| 功能模块 | 详细描述 |
|---------|---------|
| **封面区域** | 大尺寸封面图 + 遮罩 + 天数晚数 + 标题 + 地点 + 日期 + 作者信息（头像/昵称/关注按钮）|
| **交互栏** | 四个操作：❤️点赞 / 💬评论 / ⭐收藏 / 📤分享，显示对应数量 |

| **地图 Tab** | 嵌入地图展示路线 + 顶部统计卡片（总距离/预计耗时/途经点）+ 路线方案切换 + 途经点列表 + 导航按钮 |

| **评论 Tab** | 评论列表（头像/昵称/内容/时间/点赞）+ 展开收起回复 + 回复/删除操作 + 底部固定输入框 |

### 3.5 登录页

| 功能模块 | 详细描述 |

## 四、设计规范

### 4.1 视觉风格
- **风格**：扁平简约、卡片式设计、大量留白
- **主色**：`#2EC4B6`（青绿）— 传达清新、自然的旅行感
- **辅助色**：`#FF6B6B`（红）、`#FFB74D`（橙）、`#7B61FF`（紫）
- **圆角**：小 12px / 中 16px / 大 24px
- **阴影**：轻量阴影 `0 2px 8px rgba(0,0,0,0.04)`
- **图标**：统一线性 SVG 图标风格

### 4.2 深色模式
- 支持手动切换深色/浅色主题
- 暗色模式下背景 `#111`，卡片 `#1a1d26`，文字 `#e4e6eb`

### 4.3 交互规范
- 按钮点击有缩放反馈（`scale 0.96~0.98`）
- 弹窗底部弹出 + 遮罩淡入（过渡 0.25~0.3s）
- 加载状态使用旋转 spinner + 提示文案
- 空状态展示图标 + 文案 + 引导操作按钮
- 表单输入有实时验证反馈

### 4.4 布局规范
- 桌面端：居中布局，最大宽度 1200px
- 平板/手机端：全宽自适应
- 发现页瀑布流：双列自适应分配

## 六、关键流程

### 6.1 核心用户旅程
```
用户打开应用 → 发现页浏览灵感 → 切换到规划页
  → 填写目的地/日期/偏好 → AI 生成行程
  → 查看结果 / 调整排序 / 切换日期
  → 保存行程 / 发布到广场 / 同步日历
```

### 6.2 徒步专项流程
```
选择"徒步"出行方式 → 展开徒步表单
  → 填写路线类型/景观偏好/路况要求/体力限制
  → AI 生成徒步行程（含分段路线、爬升数据、难度评级）
  → 展示徒步统计 + 路段详情 + 安全提示
```

### 6.3 版本管理流程
```
生成行程后 → 点击"更多" → 打开版本管理弹窗
  → 保存当前版本为快照（可备注）
  → 浏览历史版本列表
  → 选择恢复某版本（自动备份当前版本）
```
