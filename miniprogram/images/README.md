# 图片资源说明

## 需要准备的图片资源

请将以下图片放置在 `images/` 目录下：

### TabBar 图标 (81x81px)

1. **tab-home.png** - 首页图标 (未选中)
2. **tab-home-active.png** - 首页图标 (选中)
3. **tab-discover.png** - 发现图标 (未选中)
4. **tab-discover-active.png** - 发现图标 (选中)
5. **tab-trips.png** - 行程图标 (未选中)
6. **tab-trips-active.png** - 行程图标 (选中)
7. **tab-profile.png** - 我的图标 (未选中)
8. **tab-profile-active.png** - 我的图标 (选中)

### 地图标记图标

1. **marker-spot.png** - 景点标记 (60x60px)
2. **marker-hotel.png** - 酒店标记 (60x60px)
3. **marker-restaurant.png** - 餐饮标记 (60x60px)
4. **marker-start.png** - 起点标记 (60x60px)

### 用户头像

1. **avatar1.png** - 默认头像 1 (100x100px)
2. **avatar2.png** - 默认头像 2 (100x100px)

### 其他图标

1. **logo.png** - 应用 Logo (200x200px)

## 图标设计规范

- **风格**: 扁平化、简洁
- **主色调**: #3A7BD5 (科技蓝)
- **背景**: 透明背景
- **格式**: PNG

## 临时方案

开发阶段可以使用微信开发者工具自带的图标库，或从以下资源获取：

- [iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [Flaticon](https://www.flaticon.com/) - 免费图标资源
